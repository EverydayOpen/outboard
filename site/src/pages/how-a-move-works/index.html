02 · How it works

How a move works

{{statusNote}}

  1. Choose a driveOutboard looks at the drive without changing it and tells you what it found. It refuses network volumes, FAT and exFAT, a Time Machine destination and anything it cannot identify, and it prefers one APFS volume that you made for it. It writes one small marker file on the drive and nothing else until you start a move.
  2. Checks before anything changesThe app that owns the folder must not be running (Outboard asks you to quit it and never quits anything), the drive needs room for the copy plus a margin, and nothing involved may sit in iCloud. A check that cannot be answered counts as a failed check.
  3. {{eduS1}}The folder is copied to a staging folder on the drive, then every file is compared with the original by size and SHA-256. One difference stops the move; your Mac has not changed at that point.
  4. {{eduS2}}The original is renamed to <name>.before-move. Then either the app's own setting is pointed at the copy, or a link is put where the folder was.
  5. Confirm or roll back{{eduS3}} Try the app. If it works, confirm: the original goes to the Trash and the space returns when you empty it. Until then you can roll back and the original is put back as it was.

The rules every step follows

  1. Nothing is deleted

    The original is renamed. Only after you confirm does it go to the Trash, and the Trash is yours to empty.

    trashItem

  2. The log comes first

    The line for a step is written and flushed to disk before the step runs. If the log cannot be written, nothing moves.

    fsync

  3. Unknown means no

    A check that cannot be answered refuses the move or asks you to tick a box. It is never read as "yes".

    unknown = no

  4. The guard reads facts, not memory

    Each decision starts from what the file system says about the path now, so a crash leaves nothing to repair, only to look at.

    lstat

  5. Every file is compared

    The copy is read back and compared with the original by size and SHA-256; one mismatch aborts, and the Mac is unchanged.

    SHA-256

  6. A drive is recognised by identity

    Volume UUID, a sentinel file and a stamp on the drive's root, never its name or path. A second drive with the same name is not the drive you moved to.

    UUID

  7. The note is read-only

    The note put where a folder was is a small file that cannot be written to without a permission change.

    0444

  8. Three system commands, no shell

    Two only read (the disk's facts, the Time Machine destinations). One reads and writes the catalogue's Xcode settings and nothing else. No helper, no administrator password.

    3 commands

What it reads. What it never does.

Reads

  • Folder names and sizes

    In your Library and home dot-folders, for the folders in the catalogue.

  • Mounted drives

    What macOS says about them, through two read-only system commands.

  • File contents, to hash them

    Only during a copy, to compare the copy with the original, and for Outboard's own log and marker files.

Never

  • Connect to a network

    No update check, no telemetry, no account.

  • Delete anything

    The Trash only, after you confirm.

  • Format, mount or eject a drive

    Disk Utility does that. Outboard shows the steps and never sees a passphrase.

  • Quit or signal an app

    It asks you to quit. No launchctl, no helper, no root.

  • Touch iCloud

    Not the source, the destination, staging or the log.

  • Edit your shell files

    An environment line is shown as text to copy.

If you unplug the drive

{{eduLimit}} While Outboard is running, the Drive Guard {{guardVerb}} that the drive is gone, waits {{parkSeconds}} seconds in case it comes straight back, puts a note where the folder was (or puts the app's setting back) and says so in the window and the menu bar. When the drive returns, it puts things back and checks them: a quick check and a sample of {{sampleFiles}} files, or every file that has not changed after a removal without ejecting.

Things this does not cover: Outboard has to be running (it can start at login, and it asks first); what each app does when it finds the note instead of its folder has not been tried on a real Mac; and a drive removed during a copy leaves the original where it was and a half-copied staging folder on the drive, which the next launch reports. The long version, with sources.

Limits, said plainly

  • It makes no claim about speed. A drive on a cable is not the Mac's own storage.
  • It cannot configure a new install for you: macOS gives no hook for that. It measures, moves what is on its list, and guides the rest.
