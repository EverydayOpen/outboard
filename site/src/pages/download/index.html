Not yet tried on a real Mac. Moves that change anything stay hidden in the app until you turn on "Show moves not yet tried on a real Mac". Start with data you can rebuild, and keep your own backup of anything else.

  1. Download from ReleasesTake the latest build from GitHub Releases and check it against the SHA256SUMS (or .sha256) file attached to the same release, not the editable notes: run shasum -a 256 -c next to the download. Use no other site, and never paste a Terminal command to install it.
  2. Move Outboard to ApplicationsOpen the download and drag Outboard into the Applications folder.
  3. Open it the first timePublic builds are unsigned betas until there is a Developer ID, so macOS blocks the first launch. On macOS 13 and 14, right-click Outboard, choose Open, then Open again. On macOS 15 or later, open it once, then go to System Settings › Privacy & Security and choose Open Anyway.

Or build it yourself

Everything is in the repository. You need a Mac with Xcode and XcodeGen; the steps are in the README.

Outboard makes no network connections and is not affiliated with or endorsed by any app it lists. Read how a move works first, including what it cannot do.
